这个文件夹就是「风格库」：一条风格 = 一个 .txt 文件。

- 文件名（去掉开头的「01-」这种序号）= 下拉框里显示的风格名
- 文件内容 = 交给模型的提示词（英文效果最好，用 UTF-8 保存）
- 序号只用来决定下拉框里的排列顺序，不显示
- 以 _ 或 . 开头的文件会被忽略（比如本文件）

新增一种风格：
  1. 在这个文件夹里新建一个 .txt，例如「03-油画.txt」，把提示词写进去
  2. 回到浏览器按 F5 刷新页面 —— 下拉框里就会出现新风格

只改已有风格的提示词：直接编辑对应的 .txt 文件，然后重新 Queue 即可（不用刷新）。

注释（2026-09-28 新增）：
  文件里行首的 # 或 // 开头的行会被当作注释，读取时自动剔除，不会交给模型；
  /* ... */ 块注释也可以（可跨行）。行中间的 # 不算注释（避免误伤 #ff0000 色值）。
  想临时停用某段提示词：把它单独放在一行，行首加 # 即可。
  注意：这只对风格 .txt 文件生效；节点上的文本框是「覆盖用」的原文，不做注释剔除。

负向提示词（2026-09-29 新增）：
  文件里单独写一行 ---负向--- （或 ---NEGATIVE---），它下面的内容就是该风格的
  负向提示词，从选择器的「negative」输出口送出（正向出口只送分隔符之前的内容）。
  没写分隔符的风格，负向输出为空串。
  想临时改负向词：直接编辑 .txt 里的负向段，重新 Queue 即可（不用重启）。

通用规则 vs 单张照片（2026-09-29 定稿）：
  风格库 .txt 只放**通用规则**（这类需求都要遵守的写法与禁令）；
  单张照片才有的信息 —— 人物、人数、年龄、年代、服饰 —— 填在节点界面的
  「describe」（追加到库正向之后）和「avoid」（追加到库负向之后）两个框里，
  会跟着工作流一起保存。换照片只改这两个框，不用动本文件。
  各风格文件里留了可整段复制的示例（在 # 注释里）。

写法建议（2026-09-28 实测，2026-10-29 按官方规范修订）：
  本工作流用的是「编辑类」模型（Qwen-Image 图生图），它对**指令式句子**的响应
  明显好于单纯的 tags 堆叠。推荐结构：

    <tags 段：描述质感/光学>  high definition, sharp focus, clear detail,
                              photorealistic, raw photo, DSLR, crisp
    <指令段：说清「做什么 + 锁住什么」>  Enhance this photograph to high definition: ...
                                        It stays a photograph — the original scene,
                                        the people and their facial identity ...

  只写 tags 不说「做什么」，模型容易自由发挥（4.png 实测过：少了指令段，画质提升
  有限）；只写指令不加质感 tags，质感会偏软。两句一起写效果最好，见 03-hd_img.txt。

  ⚠️ tags 段**不要**写 masterpiece / best quality / 8k / 4K / highly detailed /
  ultra-detailed。阿里官方 Qwen-Image-2.1 提示词规范明确禁用这类空泛画质词：
  它们不提供任何可执行的视觉信息，只会把结果往插画/动漫域拉。想提升清晰度，
  写具体的光学与材质描述（sharp focus、visible brush strokes、paper fibre）。
  `python scripts/check_prompts.py` 会扫描并报出这类词。

  ⚠️ 画幅比例与分辨率不要写进提示词正文，交给画布节点。写「9:16」「4K」
  不会真的改变出图尺寸，只会干扰模型。

  ⚠️ 做「照片增强/修复」类风格时，别启用 anime / illustration / watercolor 这类
  会把结果拉向插画域的词（否则真人照片会被二次元化）。

想从零写一条新提示词：
  参考 `_槽位模板.txt`（同样以下划线开头，不出现在下拉框里）。里面有三套填槽骨架
  —— 文生图 / 照片风格化 / 照片增强 —— 按官方规范压缩而成，〈 〉里填空即可。
  核心四条：保真只点名位置与角色、不描述外观；光照单独成句；不堆空泛画质词；
  一次只改一个维度。

想让模型帮你反推一种风格（拿到一张喜欢的图，想知道该写什么词）：
  1. 把参考图放进 input/style_refs/，两种放法任选：
       子文件夹：input/style_refs/水墨/1.png   → 生成 styles/水墨.txt
       平铺：    input/style_refs/水彩.png     → 生成 styles/水彩.txt
     一个风格放多张图时，只有按文件名排序的第一张会被用上（多图不自动合并，
     合并容易掺进不属于该风格的词；想更准就换一张更有代表性的图重跑）。
  2. 启动 ComfyUI（脚本走它的接口，复用已装的 Qwen3-VL-8B，不额外下模型）
  3. python scripts/gen_style_from_images.py            # 先预览，不写文件
     python scripts/gen_style_from_images.py --write    # 确认后写入 styles/
  4. 浏览器 F5，新风格就出现在下拉框里。

  ⚠️ 反推出来的只是**草稿**：它看得见那张图，看不见本项目约定（cfg 1.0、保真条款
  怎么写、别堆空泛画质词）。文件末尾留了检查清单，用之前过一遍，
  再用 python scripts/check_prompts.py 体检。
