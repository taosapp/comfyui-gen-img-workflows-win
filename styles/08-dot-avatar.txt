#   点小到糊成一片灰噪点，背景深灰、带大量灰阶，完全不像参考图那种「清晰可数的大点」。
# 根因三条：
#   1. `halftone` 是**均匀印刷网点**，这个分辨率下必然糊成灰——它和 stipple 点画是两种东西；
#   2. `textured paper` / `vintage print` 让背景发灰发脏，永远得不到纯白；
#   3. **没限定点的尺寸和间距**，模型就画到最小最密
#      （同 06 浓烈油画的教训：笔触不限尺寸就变细碎，点同理）。
# 这次改法：删 halftone / textured paper / vintage print / bold lines；
#   把「点要大、能单独看见、阴影密高光疏」和「背景是空白白纸」写成正向硬要求。
#
# 调参：
#   - 点还是太小 → 加强 large clearly separated dots、each dot reads as a separate mark；
#     别加 detailed / high resolution，那会把点推得更密；

#     cfg 1.0 下负向不生效，只能在正向写 background stays plain empty white paper；
