# 关于「高光面积调大」——这不是一个参数：
#   - cfg 已固定 1.0（Turbo 配方），denoise 固定 1.0，都没有"对比度"旋钮；
#   - 高光面积是结果：点变大 → 单位面积点变少 → 间隙变白 → 高光自然变大；
#   - 再加提示词点名留白区，两条一起才有效。
#   如果原片本身很暗，可先在 describe 里说明「整体提亮、受光面扩大」，但会牺牲结构保真。
#
# 点形状（v4 新增）：tags 里写死了 every dot is a perfect circle。
#   想换成方块／菱形等，改这一句即可；或按下面「形状标记」用一句话切换。
#   实测形状指令对模型有效，但优先级低于"密度/留白"——形状改了、密度太密，
#   照样糊成一片，所以先保证点大、留白足，再谈形状。
